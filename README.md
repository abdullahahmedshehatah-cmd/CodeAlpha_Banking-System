# Banking System

A simple **Banking System** developed using **C++** as part of my **CodeAlpha Internship**.

## Project Description

This project is a basic banking system that uses **Object-Oriented Programming (OOP)** in C++.

The system allows customers to manage their accounts and perform basic banking operations such as deposits, withdrawals, money transfers, and viewing transaction history.

## Features

* Create and manage customers
* Create and manage accounts
* Display customer and account information
* Deposit money
* Withdraw money
* Transfer money between accounts
* Store transaction history
* View transaction history
* Display account balance

## Technologies Used

* C++
* Object-Oriented Programming (OOP)
* Classes and Objects
* Arrays
* Functions
* Loops
* Conditional Statements

## Classes Used

### Customer

Stores customer information such as:

* Customer name
* Customer ID
* Account information

### Account

Manages:

* Account number
* Account balance
* Deposits
* Withdrawals
* Money transfers
* Transaction history

### Transaction

Stores:

* Transaction type
* Transaction amount

## How It Works

The program displays a menu that allows the user to select an operation.

For example:

```text
1. Show Account Information
2. Deposit
3. Withdraw
4. Transfer Money
5. Show Transactions
6. Exit
```

The user selects an option and enters the required information.

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/USERNAME/CodeAlpha_BankingSystem.git
```

### 2. Open the project folder

```bash
cd CodeAlpha_BankingSystem
```

### 3. Compile the program

```bash
g++ main.cpp -o banking
```

### 4. Run the program

```bash
./banking
```
